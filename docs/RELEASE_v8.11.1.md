# الإصدار v8.11.1 — مركز التشخيص الملكي بالأزرار وتعريب الأسباب (2026-11-27)

> بلاغ المالك: بطاقة التشخيص الحي «سيئة للغاية» — جدار نصي طويل مقطوع، أسباب
> إنجليزية خام، تكرار الفحص الحي داخل البطاقة الكاملة.
> هذا الإصدار يوحّد عرض التشخيص بالطراز الملكي: بطاقة مختصرة + أزرار + عربية
> كاملة، دون أي تغيير في قواعد التداول أو البيانات.

## الجديد

### 1) 🔍 مركز التشخيص بأزرار
- البطاقة الرئيسية تفتتح بـ **«⛔ المانع الرئيسي الآن»** — الجواب من أول نظرة
  (السقف الممتلئ، مفتاح القتل، الأخبار بلا بيانات، أو حالة سوقية صادقة)، ثم
  سطر البوابات المضغوط، وعدّادات السقف، و**إجمالي آخر دورة مجمّع**.
- الأزرار الأربعة:
  - **🧪 فحص بيانات حي** — بطاقة مستقلة لنتيجة الفحص وحدها + زر إعادة.
  - **🌐 قرار كل سوق** — صفحات (6 أسواق/صفحة) بقرار آخر دورة لكل سوق.
  - **🧾 سجل المحرك** — صفحات (8 قرارات/صفحة) من `engine_runs` بترقيم.
  - **🛡 إدارة السقف** — العدّادات الحية + قائمة الإشارات المفتوحة بأعمارها +
    زران فعليان: «📡 إدارة الإشارات المفتوحة» و«🛡 إدارة المخاطر» (رفع السقف
    يبقى من صفحة المخاطر المعتمدة، إجراء إداري مسجّل).

### 2) 🇸🇦 تعريب شامل لأسباب المحرك
طبقة عرض جديدة (`fysb/theme.py`): `ar_result` / `ar_reason` / `ar_run_line` —
تُترجم في **كل** مواضع العرض: التشخيص وصفحاته، سجل المحرك، صفحة المحرك،
بطاقات الصمت الإدارية، وبطاقة «تقرير الفحص المؤسسي» التي تصل للمستخدم:

| السجل الخام | ما يُعرض الآن |
|---|---|
| `MARKET_CLOSED · session calendar says…` | 🌐 السوق مغلق الآن وفق تقويم الجلسات |
| `QUALITY_REJECTED (68 < 72)` | ⭐ الجودة دون الحد المؤسسي — مع التفصيل العربي |
| `RISK_REJECTED (7/7)` | 🛡 بوابة المخاطر رفضت — سقف/حد وقائي |
| `data stale (age 942min)` | ⏳ بيانات أقدم من الحد المسموح (942 دقيقة) — رفض صادق |
| `ER=0.02 < 0.18` | 🌊 (نص الدرع العربي للمتذبذب كما هو) |

الأسباب العربية المؤسسية الأصلية تمرّ كما كتبها المحرك، والسجل الداخلي
(`engine_runs`) يبقى بالرموز الخام الصادقة للفحص الآلي.

### 3) الحدود
- كل صفحة تحت حد تيليجرام 4096 حرف بأمان؛ لا تكرار ولا قصّ في المنتصف.
- لا ترحيل بيانات، لا تغيير للصلاحيات أو الحسابات.
