# الدليل الملكي — رفع البوت إلى GitHub (خطوة بخطوة)

الوقت المطلوب: 5 دقائق. المستودع: **خاص (Private)** باسم `ForexYemeni_Bot`، ترخيص **حقوق محفوظة**.

---

## الخطوة 1 — إنشاء المستودع (مستودع فارغ — مهم جداً)

1. افتح: `github.com/new` (تسجيل الدخول بحسابك).
2. **Repository name**: `ForexYemeni_Bot`
3. اختر **Private**.
4. **لا تضف** أي من: README أو .gitignore أو license — **المستودع يجب أن يُنشأ فارغاً** وإلا سيرفض الرفع الأول.
5. اضغط **Create repository** — لا تنفذ أي أمر يعرضه على الصفحة (سكربتنا يتولى كل شيء).

## الخطوة 2 — إنشاء توكن الرفع (Personal Access Token)

1. GitHub ← صورتك أعلى اليمين ← **Settings**.
2. آخر عنصر يساراً: **Developer settings**.
3. **Personal access tokens → Tokens (classic)** ← **Generate new token (classic)**.
4. Note: `bot-upload` — Expiration: 90 يوم (أو ما يناسبك).
5. فعّل صلاحية واحدة فقط: **repo** (كاملة).
6. **Generate token** ← انسخ التوكن فوراً (يظهر مرة واحدة فقط).

> التوكن يُستخدم مرة واحدة في سكربت الرفع ثم يُحذف تلقائياً من الإعدادات المحلية.
> لا تشاركه مع أي شخص — ويمكنك إبطاله في أي وقت من نفس الصفحة (Delete).

## الخطوة 3 — فك ضغط الحزمة

فك ضغط `ForexYemeni1_GitHub_Kit.zip` — ستحصل على مجلد واحد: `forexyemeni-bot`.

## الخطوة 4 — الرفع بضغطة واحدة

افتح الطرفية (Termux على الهاتف، أو Terminal / PowerShell على الكمبيوتر):

```bash
cd مسار/forexyemeni-bot
bash UPLOAD_TO_GITHUB.sh
```

سيطلب منك: اسم المستخدم ← التوكن ← ثم ينهي كل شيء تلقائياً
(init + add + commit + push + حذف التوكن من الإعدادات).

## الخطوة 5 — التحقق

1. افتح: `github.com/ForexYemeni/ForexYemeni_Bot` — سترى كل الملفات.
2. تبويب **Actions** ← يبدأ «Royal Tests» تلقائياً ← بعد دقيقتين علامة **خضراء** = 189/189 ناجحة.
3. الشارة أعلى README مضبوطة مسبقاً على مستودعك وستظهر خضراء بعد أول رفع.

## تحديثات لاحقة (عند أي تعديل)

```bash
cd ForexYemeni_Bot
git add -A
git commit -m "وصف التعديل"
git push            # سيطلب المستخدم/التوكن أو يستخدم بيانات git المحفوظة لديك
```

## مشاكل شائعة

| الرسالة | السبب والحل |
|---|---|
| `Authentication failed` | التوكن خاطئ أو منتهي — أنشئ توكناً جديداً وأعد السكربت |
| `remote origin already exists` | طبيعي — السكربت يحذفه ويعيد إضافته تلقائياً |
| `rejected — fetch first` | المستودع لم يُنشأ فارغاً (فيه README تلقائي) — احذف المستودع وأنشئه فارغاً |
| `nothing to commit` | لا تغييرات جديدة — طبيعي عند تكرار التشغيل |

> الأمان: `.env` وقاعدة البيانات والسجلات والنسخ الاحتياطية **محجوبة بـ .gitignore** ولن تُرفع أبداً — تحقق من ذلك بعد الرفع (لن تجد ملف .env في المستودع).
