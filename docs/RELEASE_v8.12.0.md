## ثانياً: ترقية المحركات الثلاثة إلى الامتلاء الميكانيكي

مبدأ الترقية: **«الترقيات ترفع ولا تُنقص»** — كل العوامل الجديدة مكافآت تُضاف
إلى earned دون تضخيم المقام، فتبقى درجات التراث ثابتة وتتحسن مع الجودة الأعلى.

### WYCKOFF — من Spring/Upthrust إلى المدرسة الأوسع
- **دخول ثانوي LPS/LPSY**: Spring خلال آخر 10 شموع، استعادة الحد، تراجع سطحي
  متماسك، وإغلاق مؤكد — مع صحة حجم التراجع (<0.8× المتوسط) عند توافره.
- **جهد مقابل نتيجة**: حجم كبير مع انتشار ضيق = امتصاص → خصم معلن في الأسباب.
- **تقصّر الدفعة**: محاور مضادة تضيق داخل النطاق قبل الحدث → عامل نقاط.
- كل نافذة LPS تحسب نطاقها النظيف **قبل** الحدث (ذيل الاجتياح لا يلوّث النطاق).

### ICHIMOKU — عوامل الجودة الكاملة
- ارتداد كيجون/إعادة اختبار نفق TK، نضارة انقلاب الكومو (≤10 شموع)، تشيكو في
  **فضاء مفتوح** فوق بنية نافذة الإزاحة كاملة (لا مرجع شمعة واحدة)، قرب كيجون.
- **عناصر الزمن العددية (Ochi) غير منفذة عمداً** وتُعلن في صفحة الهوية — لا
  مزيفة باسم مدرسة.

### PRICE_ACTION — قراءة الشموع الكاملة
- مشغلات جديدة: **الشمعة الداخلية** المنكسرة، **انعكاس الشمعتين**، **نجمة
  صباحية/مسائية** (محاذاة EMA)، **الاختراق الفاشل الفخ** (بلا شرط اتجاه،
  محكوم بالموقع)، و**ترجيح الموقع السيكولوجي** (أرقام كبرى بمرصّد ≥5 ATR
  كثافة، لمسة ≤0.25 ATR).

## رابعاً: البوابة الملكية — 18 مدرسة

السجل والتحقق والكتالوج والباقات والترتيب الأساسي كلها الآن 18 كوداً متسقة:
`REGISTRY == VERIFIABLE == IMPLEMENTED_STRATEGIES == BASELINE_ORDER`، صفوف
الكتالوج تُزرع بوصف عربي كامل، التنقية تحفظ القائمة بالضبط، وباقة ROYAL ELITE
تتضمن المدارس الخمس. كل عدّادات «13» في الواجهات صارت ديناميكية أو 18.

## خامساً: تقرير الفجوات الصادق للمدارس العشر (كما أمر المالك)

| المدرسة | المنفذ الحقيقي | ما ينقصها (صادق ولا نكّار) |
|---|---|---|
| **ICT** | HTF bias + (sweep موافق أو FVG/OB سليمة + displacement + MSS) + محاور مؤسسية | لا يوجد **Draw on Liquidity** (خريطة سيولة هدفية)، لا **Breaker/Mitigation** كسجل إبطال مرتّب، لا **SMT** (تباعد مؤشرات مرتبطة)، لا **OTE** رسمياً (0.618–0.79 شريط دخول متدرج)، PD-Arrays متعددة الطبقات غير موجودة |
| **SMC** | BOS/CHOCH + منطقة سوينغ ±1.2 ATR + محاور | لا **مجمعات EQH/EQL** كمصايد سيولة صريحة، لا **فلتر الإغراء (Inducement)**، عرض المنطقة ديناميكي وليس ثابتاً حسب المدرسة، منطقة واحدة لكل قرار (لا تدرّج مناطق) |
| **CRT** | مرجع آخر 4 شموع ≥0.55 ATR، اجتياح جانب واحد، إغلاق داخلي، دخول 50% | لا مراجع **أسبوعية/يومية أعلى** حقيقية، لا **سلّم شموع متعدد** (Ladder) للتأكيد التدريجي |
| **AMD** | نطاق آسيا 00–06 UTC + نطاق محلي 8+6، اجتياح وإغلاق داخلي | لا **POI بعد التلاعب** صريح، لا أهداف **توزيع D** قائمة على معادلة المدى الكامل، Killzone لندن غير إلزامي |
| **SILVER_BULLET** | نوافذ NY DST 03–04/10–11/14–15، انحياز النطاق، FVG داخل النافذة، رفض الفجوات المكسورة | لا **بروتوكول 1-2-3** التأكيدي داخل النافذة، لا **NWOG/NDOG** (فجوات العطلات/اليوم) كمصدر انحياز |
| **TREND** | ترتيب 9/21/50 ±0.25 ATR + زيارة قيمة EMA21 تاريخية بلا lookahead + استئناف | لا **ADX** أو مقياس قوة اتجاه كمّي، لا تمييز مراحل (تمدد/انضغاط) |

| **FIBONACCI** | ساق ≥2.5 ATR/40 شمعة + جيب 61.8–78.6 | الـ**OTE** الرسمي (شريط 0.618–0.79 مع تأكيد) غير منفذ كامل، لا **Equal-ish 50% EQ** كمستوى قرار |
| **CLASSIC** | جانب EMA50 وميله + مستوى ≤2 ATR + تأكيد 3 شموع | لا **إثبات تبديل الأدوار** تاريخياً (مستوى قديم يُختبر ويرفض)، لا **المستويات السيكولوجية** كطبقة مستقلة |
| **SK** | مفتاح مشروع: كسر 12 شمعة بإغلاق + زخم + EMA | ليست مدرسة خارجية أصلاً — معلنة بصدق كمفتاح سكالبينج خاص بالمشروع؛ لا إضافات مطلوبة |
