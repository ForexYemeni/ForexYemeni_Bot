# v8.14.19 — «التقرير الموحد الفاخر + قانون الخمسين نقطة»

## أمر المالك: تقرير واحد فقط — فاخر، شامل حقيقي 100%، تفاعلي من الألف إلى الياء

«بث تقرير الأداء» و«التقارير الشاملة» **أُعدما** واستُبدلا بنظام واحد موحّد،
مع مرسوم ملكي ميكانيكي: **أي صفقة لمست عتبة الخمسين نقطة لا تُعد خاسرة أبداً —
ربحها الحقيقي هو عتبة التأمين 100%.**

### ① القانون الملكي — دفتر الحقيقة `fysb/services/ledger.py`
- **`closed_verdict(row, lock_pips_v=None)`** — الحكم الواحد لكل صفقة مغلقة:
  - كل حالة ربح (TP1/TP2/TP3/BE/CLOSED_WIN/WIN/LOCKED_50) → **رابحة** بنقاطها.
  - وقف خسارة (SL_HIT/LOSS) **مع `profit_50_hit=1`** → **رابحة عند عتبة التأمين**
    (`lock_pips` — افتراضي 50، قابل للتعديل 20–500 من إعدادات الصدق، اختُبر بـ70).
  - وقف خسارة بلا لمس العتبة → خاسرة بنقاطها الحقيقية — لا شيء يُكتم.
  - غير المغلق → يتجاهل (لا أرقام شبحية).
- يقبل sqlite3.Row أو dict — يفتح اتصاله بنفسه، لا يلمس مسار التحليل.

### ② المرسوم مطبق ميكانيكياً في كل مستهلكي الأرقام
- **التقرير التفاعلي المفلتر**: الربح/الخسارة من دفتر الحقيقة + سطر إفصاح ملكي:
  «🏅 قانون الخمسين نقطة: N صفقة لمست العتبة فحُسبت رابحة عند عتبة التأمين — لا تُعد خاسرة أبداً».
- **تقرير الإشارات الكلاسيكي**: نفس الحكم — المنقذة ربح عند العتبة.
- **الديجست المؤسسي (نص + PNG + R)**: is_win/is_loss من الليدger،
  وR multiple يُحسب عبر `effective_row` (نقاط المنقذة = العتبة).
