# الإصدار v8.14.4 — «السبوت المُثبت»: نهاية بطاقة «بيانات بديلة للعرض فقط» الأبدية (2026-11-27)

> بلاغ المالك: البطاقة تتكرر دائماً عند توليد الذهب رغم السوق المفتوح. التشخيص:
> عند فشل سبوت ياهو في دورة ما، كان الذهب **بلا أي بيانات درجة-إشارة بالتصميم** —
> حتى حمولة العقود المُثبتة بالفحص المتقاطع (مطابقة للسبوت بالسنت) كانت محجوبة
> بحاجز is_proxy الأبدي.

## الإصلاح — الحائط يفتح بالدليل فقط، لا بالإيمان
1. **ترقية CALIBRATED_SPOT**: حمولة العقود التي تجتاز **الدليلين معاً** — تعويض
   اقتباس↔اقتباس بعمر ≤30 دقيقة **و** انحراف لحظي ضيق عن السبوت الحقيقي
   (≤ max(2$، 0.1%، 1×ATR15)) — تُعلَّم CALIBRATED_SPOT وتصبح **درجة-إشارة**
   (is_proxy=False + spot_proof موثق على الحمولة). #46 باقٍ: الخام/غير المُثبت يبقى PROXY «للعرض فقط».
2. **إنصاف حارس التدهور**: أخطاء ياهو وقت إغلاق السوق الأسبوعي **ليست فشلاً** —
   لا تبني عدّاد التدهور (كانت ستخطي السبوت الـ15 دقيقة بلا وجه حق).
3. **النتيجة البنيوية**: الذهب له **مصدران مستقلان درجة-إشارة** (سبوت ياهو، أو
   العقود المُثبتة) — الموت المزدوج وحده يوقف التوليد، والبطاقة حينها تسمي الميتين بالتشخيص الملكي.

## عطلة حقيقية أمسكتها الاختبارات قبل الإنتاج
المتغير `offset_applied` لم يكن مُعرَّفاً في مسار PAXG البديل → NameError كان
سيقتل المسار كلياً عند أول استخدام إنتاجي — أُصلح (متغير مشترك بين المسارين).
