# الإصدار v8.13.7 — إغلاق اليوم الملكي + اللوحة المتجددة يومياً (2026-11-27)

> طلب المالك الثلاثي: ① لوحة المخاطر تتجدد كل يوم ② قبل نهاية اليوم بـ30 دقيقة
> تُغلق كل الإشارات مع تنبيه إجباري («يوم جديد إشارات جديدة ونظام جديد»)
> ③ زر إغلاق فوري في محرك المخاطر — والبوت يواصل البحث 24 ساعة دون توقف.

## 1) إغلاق يوم التداول الملكي (مجدول يومياً)
- ساعة قابلة للضبط `eod_close_utc` (الافتراضي **21:30 UTC** = قبل نصف ساعة من
  إغلاق السوق 22:00) — تنطلق مرة واحدة كل يوم UTC.
- **كل الإشارات المفتوحة تنتهي مع اليوم**: ACTIVE/RUNNING → EXPIRED بمحاسبة
  صادقة (لا نتيجة مفبركة — الحامل يغلق صفقته الحقيقية بالسعر الحالي)؛
  الفائزات المخبأة TP1/TP2 **تحتفظ بانتصارها** ويُوقف تتبعها فقط.
- **التنبيه الإجباري** لكل حامل + الإدارة مرة واحدة لكل مستخدم (لا سبام):
  «🌙 تُغلق جميع الصفقات قبل إغلاق السوق — يوم جديد، إشارات جديدة، ونظام جديد»
  مع تحرير بطاقات الإشارات الحية فوراً.
- **البوت لا يتوقف**: البحث عن الفرص يستأنف فوراً مع اليوم الجديد (24 ساعة
  دون توقف كما أراد المالك) — الإغلاق للصادرة فقط، لا للبحث.

## 2) اللوحة المتجددة + الزر الجديد
- بعد الإغلاق اليومي تُرسل للإدارة **لوحة المخاطر المجددة** (عدّادات اليوم
  صفرت، «نظام جديد») — اللوحة نفسها تعرض الآن ساعة الإغلاق وآخر إغلاق.
- زر جديد في المحرك: **«🌙 إغلاق يوم التداول الآن»** — إغلاق فوري يدوي بنفس
  المنظومة (كل المفتوحة + التنبيه الإجباري + ختم يوم جديد) بضغطة واحدة.

## 3) توضيح مفتاح القتل (Kill Switch) — داخل اللوحة أيضاً
مفتاح القتل **للطوارئ فقط**: يوقف إصدار كل الإشارات الجديدة فوراً (الصادرة
تُتابع) للخطر البنيوي الكارثي. الاستخدام اليومي الصحيح لنهاية اليوم هو زر
«إغلاق يوم التداول» — والفرق مكتوب الآن داخل اللوحة نفسها.
